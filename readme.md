# Enter The Market

A retro, Windows-95–style inventory and trading game built in **Python + Pygame**.

Buy low, sell high, manage limited storage, pay weekly rent, react to market news, and slowly build a profitable operation.  
The game focuses on **systems, data, and decision-making**, not reflexes.

All game state persists via **CSV files**, making it easy to inspect, tweak, or extend.

---

## Controls

### Mouse
- Click buttons to buy, sell, craft, and navigate tabs  
- Click quantity boxes to type amounts  

### Keyboard
- **Number keys** — enter quantities  
- **Backspace** — edit quantity inputs  
- **Enter** — confirm input / exit field
